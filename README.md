# עגלות קפה ביו"ש

אפליקציית רשת (PWA) שמציגה על מפה את עגלות הקפה והפודטראקים ביהודה ושומרון.

- הנתונים נטענים בכל פתיחה מהגיליון "פודטראקים/עגלות ביו"ש".
- עם מפתח Google Maps (Places API New) האפליקציה מוסיפה שעות פתיחה, טלפון, סגירה זמנית או לצמיתות, ועגלות חדשות שמופיעות בגוגל מפות.
- ברירת המחדל: רק מה שפתוח עכשיו.
